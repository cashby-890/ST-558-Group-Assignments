The dataset contains 8,760 hourly observations across 365 dates. Hourly bike rentals average 704.6, ranging from 0 to 3,556. Temperatures range from -17.8 Celsius to 39.4 Celsius, while rainfall and snowfall are typically 0. Date and categorical variables require conversion before further analysis. There are no missing values across all fields.

When functioning_day == ‘No’, rental counts are zero across all hours because the bike-sharing networked was closed for service. We remove non-functioning days so unserviced periods do not distort natural consumer weather demand.

Hourly to Daily Aggregation

Group by date, seasons, and holiday, calculate sum of bike_count, rain and snowfall, calculate means of temp, humidity, wind_speed, visibility, dew_point_temp, and solar_radiation

bike_daily <- bike_functional |>

  summarise(
   bike_count = sum(bike_count),

   across(
     c(temp, humidity, wind_speed, visibility, dew_point_temp, solar_radiation),

Computing Mean/Std Dev for Numeric Predictors / Separate Weekend/Weekday from date using lubridate

# Identify numeric predictor columns
num_cols <- c("temp", "humidity", "wind_speed", "visibility", "dew_point_temp", "solar_radiation", "rainfall", "snowfall")

# 1. Separate weekdays and weekends
add_day_type <- function(df) {
  df |>
    mutate(
      day_type = factor(if_else(wday(date) %in% c(1,7), "Weekend", "Weekday"))
    )
}

train_prep <- add_day_type(train_raw)
test_prep <- add_day_type(test_raw)

# 2. Extract training means and sds
train_means <- sapply(train_prep[num_cols], mean)
train_sds <- sapply(train_prep[num_cols], sd)

# 3. Standardize training set
train_std <- train_prep
train_std[num_cols] <- scale(train_prep[num_cols], center = train_means, scale = train_sds)

# 4. Standardize test set using training parameters
test_std <- test_prep
for (col in num_cols) {
  test_std[[col]] <- (test_prep[[col]]-train_means[[col]])/train_sds[[col]]
}

Fitting Multiple Linear Regression Models

\[\text{RMSE} = \sqrt{\frac{1}{n_{\text{test}}} \sum_{i=1}^{n_{\text{test}}} (y_i-\hat{y}_i)^2}\]

calc_rmse <- function(actual, predicted) {
  sqrt(mean((actual - predicted)^2))
}

Model 1 : Main Effects

Includes all standardized numeric predictors plus seasons, holiday, and day_type

m1 <- lm(
  bike_count ~ temp + humidity + wind_speed + visibility + dew_point_temp + solar_radiation + rainfall + snowfall + seasons + holiday + day_type,
  data = train_std
)

pred_m1 <- predict(m1, newdata = test_std)
rmse_m1 <- calc_rmse(test_std$bike_count, pred_m1)

Model 2 : Interaction Terms

Includes Model 1 terms plus interactions between:

  • seasons *holiday

  • seasons * temp

  • temp * rainfall

m2 <- lm(
  bike_count ~ temp + humidity + wind_speed + visibility + dew_point_temp + solar_radiation + rainfall + snowfall + seasons + holiday + day_type + seasons:holiday + seasons:temp + temp:rainfall,
  data = train_std
)

pred_m2 <- predict(m2, newdata = test_std)
rmse_m2 <- calc_rmse(test_std$bike_count, pred_m2)

Model 3 : Quadratic & Polynomial Terms

Includes Model 2 terms plus quadratic terms for temperature and humidity

m3 <- lm(
  bike_count ~ temp + humidity + wind_speed + visibility + dew_point_temp + solar_radiation + rainfall + snowfall + seasons + holiday + day_type + seasons:holiday + seasons:temp + temp:rainfall + I(temp^2) + I(humidity^2),
  data = train_std
)

pred_m3 <- predict(m3, newdata = test_std)
rmse_m3 <- calc_rmse(test_std$bike_count, pred_m3)

Final Model Fit on Full Dataset

We select the model with the lowest test-set RMSE and refit it using the complete dataset.

# 1 Feature engineering on the full dataset
full_prep <- add_day_type(bike_daily)

# 2 Standardize using full-dataset mean and standard deviation
full_means <- sapply(full_prep[num_cols], mean)
full_sds <- sapply(full_prep[num_cols], sd)

full_std <- full_prep
full_std[num_cols] <- scale(full_prep[num_cols], center = full_means, scale = full_sds)

# 3 Select winning model formula
best_formula <- formula(list(m1, m2, m3)[[which.min(c(rmse_m1, rmse_m2, rmse_m3))]])

# 4 Refit on full standardized dataset
final_model <- lm(best_formula, data = full_std)

# 4 Report coefficients and summary
