  1. What is meant by long format data and wide format data? Which do we generally prefer for statistical analysis?

Long format data refers to multiple rows for each observational unit (e.g. recurring ID numbers for test scores such as math/reading)–this is generally the preferred format for statistical analysis because it is expected by many R functions from visualization libraries (ggplot2) to statistical modeling functions (lm/ANOVA/mixed effects models).

Wide format data generally has one row for each observational unit with different measurements separated by columns (e.g. one ID number followed by a math column and a reading column).

yeast_summary <- yeast |>

Use chaining to then determine the overall win/loss records (sum of wins & sum of losses) for each of these hall of fame managers using group_by() with summarize() rather than mutate. Create a new variable that is the career win/loss percentage as column Total_W/G_managed. Sort the resulting data by the win/loss percentage variable (from largest to smallest).
manager_summary <- tbl(con, "Managers") |>
  #Select only game, win, and loss columns
  select(
    playerID, G, W, L
  ) |>
  #Group by manager to aggregate career totals in the database
  group_by(playerID) |>
  summarize(
    G_managed = sum(G, na.rm = TRUE),
    Total_W = sum(W, na.rm = TRUE),
    Total_L = sum(L, na.rm = TRUE)
  ) |>
  collect() |>
  mutate(win_loss_pct = Total_W / G_managed) |>
  arrange(desc(win_loss_pct))
